# 🌟 Behind the Filter: ESL B1 SpeakingFlow

> **An interactive, modern ESL B1 speaking masterclass and web application designed for teenagers (CEFR B1 Intermediate).**  
> Blends **Social Media & Influencers**, **Personality Types & Identity**, **Mental Health & Screen Habits**, and **Heroes vs. Celebrities** into one engaging, gamified speaking curriculum.

---

## 🎯 Overview

* **Target Level:** CEFR B1 (Intermediate)
* **Target Audience:** 16-Year-Old High School Students / Teenagers
* **Integrated Topics:** 
  1. 📱 *Social Media & The Algorithm*
  2. 🧠 *Personality Types & Self-Discovery*
  3. 🧘 *Mental Health, Self-Image & Screen Habits*
  4. 🦸 *Real Heroes vs. Internet Celebrities*
* **Core Skills:** Spoken fluency, defending opinions, polite disagreement, hypothetical reasoning (Second Conditional), giving advice, and spontaneous debate.

---

## ✨ Features

- 📚 **60+ Curated Target Vocabulary & Idioms**: With B1 definitions, part of speech, and teen-relatable example sentences.
- 💬 **38 Dynamic Speaking Prompts**: Organized into 6 progressive rounds from icebreakers to spicy ethical dilemmas.
- 🔊 **Native Audio Pronunciation**: Built-in Text-to-Speech (TTS) using browser SpeechSynthesis for every vocabulary word and question.
- 🔍 **Instant Search & Category Filters**: Search words, definitions, and examples in real time.
- 🎲 **"Random Q" Spotlight Generator**: Pick a surprise speaking question at random with one click.
- 📻 **Dr. Real-Talk Advice Clinic (Roleplay)**: 3 realistic teen letters for students to practice roleplaying as an advice podcaster.
- ⏱️ **60-Second Debate Arena**: Includes an interactive countdown timer with animated pulse effects and 5 thought-provoking motions.
- 🏆 **Everyday Superhero Award Pitch**: A 4-checkpoint structured pitch framework for a 2-minute speech.
- 🗣️ **Conversational Power-Phrases**: Color-coded scaffolds for expressing opinions, agreeing, disagreeing, and hypothetical thinking.
- 🌓 **Dark / Light Theme & Print-Ready CSS**: Distraction-free clean UI with a dedicated print stylesheet for PDF exports and worksheets.

## 🚀 How to Use / Run Locally

1. **Option 1: Direct File Open**
   - Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari). No build tools or servers required!

2. **Option 2: Local Server**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Or using npx
   npx serve .
   ```
   Open `http://localhost:8000` in your browser.

3. **Option 3: GitHub Pages**
   - Go to your repository **Settings** > **Pages**.
   - Under **Build and deployment**, select **Deploy from a branch** (`main` / `/root`).
   - Your speaking hub will be live on `https://mikegit-lb.github.io/ESL-B1-SpeakingFlow.1/`.

## 📋 Curriculum Breakdown

### 1. Vocabulary Clusters (60 Words & Collocations)
- **Social Media:** *curated feed, doomscrolling, digital footprint, influencer, authentic, clickbait, algorithm, sponsored post, engagement, aesthetic, trendsetter, shadowban, unfollow, viral, scroll endlessly.*
- **Personality Types:** *introvert, extrovert, ambivert, outspoken, overthinker, empathetic, people-pleaser, easygoing, ambitious, charismatic, self-conscious, reliable, spontaneous, adaptable, quirk.*
- **Mental Health & Wellbeing:** *self-esteem, FOMO, digital detox, burnout, peer pressure, body image, comparison trap, validation, unplug, overwhelming, boundary, mindset, self-care, recharge, insecure.*
- **Heroes & Role Models:** *role model, look up to, integrity, resilience, overcome obstacles, selfless, trailblazer, make a difference, moral compass, advocate, humble, courageous, everyday hero, inspire, superficial.*

### 2. Speaking Rounds (38 Questions)
1. **Round 1: Quick-Fire Icebreakers** (Questions 1–6)
2. **Round 2: Social Media & The Algorithm** (Questions 7–13)
3. **Round 3: Personality Types & Identity** (Questions 14–20)
4. **Round 4: Mental Health & Self-Image** (Questions 21–27)
5. **Round 5: True Heroes vs. Celebrities** (Questions 28–34)
6. **Round 6: Spicy Dilemmas & Would You Rather** (Questions 35–38)
